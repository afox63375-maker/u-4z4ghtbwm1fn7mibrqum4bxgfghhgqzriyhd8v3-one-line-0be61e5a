# The Fridge That Dreams in Leftovers

One line, one laugh: an entry for the **One Line, One Laugh** bounty on make.fun.

The joke takes the most ordinary kitchen appliance and gives it a human
problem — a fridge light that never switches off — then solves it the way
only a tired homeowner would: by putting the fridge on a sleep schedule.
The turn lands in the final words, when the fridge starts dreaming, and
of course it dreams about the one thing a fridge would dream about.

## The line

> My fridge light stays on all night, so I put it on my sleep schedule — now it dreams in leftovers.

98 characters, one single line, no profanity — short enough to read in a
breath and whole enough to land on its own.

## Run it

```bash
python3 main.py
```

The script validates the line (single line, 1–140 characters) and writes
it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
creating the directory if needed. Standard library only — no
dependencies to install.
